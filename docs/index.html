Acesso e Regras

Login por CPF

O endpoint POST /api/v1/auth/token gera um bearer token para o associado cadastrado.

Admin inicial

O primeiro admin é bootstrapado por INITIAL_ADMIN_CPF quando a aplicação sobe.

Perfis

ADMIN gerencia pautas, sessões e perfis. USER vota e pode excluir o próprio cadastro.

Endpoints públicos

As rotas de GET para associados, votos, pautas, sessões e resultado seguem sem autenticação.
